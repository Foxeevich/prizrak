# Prizrak Desktop (Electron)

Клиент для **macOS** и **Windows**. Вся E2E-крипта выполняется в main-процессе,
UI — изолированный рендерер (contextIsolation, без nodeIntegration).

## Запуск в режиме разработки

Из корня репозитория один раз поставьте зависимости, затем запустите клиент:

```bash
npm install                     # ставит зависимости всех пакетов
cd packages/desktop
npm install                     # electron + electron-builder (devDeps)
npm start                       # запустит приложение (перед этим синхронизирует lib/)
```

При старте автоматически выполняется `scripts/sync-desktop-lib.mjs` — он копирует
исходники `@prizrak/crypto` и `@prizrak/client` в `packages/desktop/lib/`, чтобы
приложение было самодостаточным при упаковке.

В окне входа укажите адрес homeserver'а (например `http://127.0.0.1:8801` для
локального сервера), имя вида `user:domain`, отображаемое имя и пароль.

## Сборка установщиков

```bash
cd packages/desktop
npm run dist:mac     # → dist/*.dmg и *.zip   (запускать НА macOS)
npm run dist:win     # → dist/*.exe (NSIS) и portable  (запускать НА Windows)
```

Сборка `dist:mac` автоматически накладывает **ad-hoc-подпись** (хук
`build/afterPack.cjs`), поэтому свежесобранное приложение открывается на вашем
Маке без ошибки Gatekeeper.

### Если macOS ругается «вредоносное ПО»

Это НЕ вирус — так macOS Gatekeeper реагирует на неподписанное приложение
(частая история с самособранными Electron-приложениями). Что делать:

- Проще всего для теста — запускать в dev-режиме: `npm start` (Gatekeeper не
  участвует).
- Если предупреждение появилось на уже установленном `.app` (macOS мог
  переместить его в Корзину — сначала достаньте обратно):

  ```bash
  bash packages/desktop/fix-macos.sh /Applications/Prizrak.app
  # или вручную:
  xattr -cr /Applications/Prizrak.app
  codesign --force --deep --sign - /Applications/Prizrak.app
  ```

- На **чужих** маках предупреждение вернётся: для раздачи без плясок нужен
  платный Apple Developer ID ($99/год) и нотаризация — это про дистрибуцию, не
  про код.

Важно: подписанный **.dmg собирается только на macOS**, а **.exe — на Windows**
(или в CI с соответствующими раннерами). Кросс-сборка `.dmg` на Linux/Windows
не поддерживается Apple. Для распространения без подписи это работает, но
пользователи увидят предупреждение Gatekeeper/SmartScreen — для продакшена нужны
сертификаты разработчика Apple и Windows code signing.

## Что уже умеет

- Регистрация/логин по `user:domain` + пароль (без телефона), с учётом тумблера
  регистрации и инвайт-кода.
- Личные чаты, группы и каналы (E2E).
- **Вложения и голосовые** сообщения (E2E-блобы).
- **Аудио- и видеозвонки без STUN** через stealth-relay (кнопки 📞/🎥).
- **Кошелёк 👻**: баланс, покупка-заглушка, отправка призраков собеседнику.
- **Пуш-уведомления**: мгновенная доставка по WebSocket + нативные уведомления ОС.
- Фирменная иконка-призрак 👻 (`build/icon.png` → `.icns`/`.ico` при сборке).

## Оговорка про медиа звонков

Захват микрофона/камеры и потоковое воспроизведение сделаны через
`MediaRecorder` + `MediaSource` (WebM/Opus) — это прототип, не низколатентный
SRTP. Транспорт медиа (stealth-relay), сигналинг и E2E-шифрование кадров —
рабочие и протестированы. Для продакшена медиапайплайн заменяется на Opus/SRTP
внутри stealth-туннеля.
